Polling Unit Analysis

How registered voters and polling units changed between the 2019 and 2023 general elections. Drill from state to LGA, ward and polling unit, or search. Polling units that did not exist in 2019 are marked “New polling unit”.

Polling units are matched on their INEC code. In 2023 INEC converted voting points into new polling units; existing units kept their codes, so the 56,874 units with no 2019 code are the new ones. Where a unit kept its code but its name changed markedly, it is marked “Renamed”. 2019 totals for FCT include 216,123 voters at voting-point settlements that were not polling units.
